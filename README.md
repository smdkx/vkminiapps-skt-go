# SKT Go

### Описание

Мини-приложение ВКонтакте на платформе VK Mini Apps с расписанием, справочником, новостями, мемами и достижениями для студентов колледжа.

> Ссылка на приложение: https://vk.com/app7469712

## Что реализовано

- **🌗 Светлая и тёмная темы.** Поддержка темы клиента ВКонтакте.
- **📱 Мобильная и ПК-версия.** Адаптивный интерфейс с боковым меню на больших экранах.
- **😍 VKUI 8.** Обновлённые компоненты интерфейса.
- **⚛️ React 19.** Основа приложения.
- **📦 Роутер.** Навигация по разделам, сохранение позиции прокрутки и поддержка SwipeBack на iOS.
- **⛓ VK Bridge.** Интеграция с ВКонтакте и сохранение пользовательских данных в VK Storage.
